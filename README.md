Material for the "Whiteboxish Macro Powers With Named Tuples" [blog](https://blog.daniel-beskin.com/2025-04-14-whiteboxish-named-tuples).

The code is an adapted version from the example in the [Quotidian](https://github.com/kitlangton/quotidian/tree/2c1ffb497bbc91f8860a965e757812d6609ff84c/examples/src/main/scala/quotidian/examples/lens) library.

Use [Scala CLI](https://scala-cli.virtuslab.org/) to build and run the code.

```bash
scala-cli run . --main-class quotidian.examples.lens.example
```
